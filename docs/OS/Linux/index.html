磁盘文件无法删除怎么处理

在删除储存卡中的文件夹时，出现以下报错：

一个意外错误使你无法删除该文件夹。错误 0x80070570: 文件或目录损坏且无法读取

  1. 运行 CHKDSK 命令：

    • 按下 Win + R 键，打开“运行”对话框，然后输入 cmd 并按回车。
    • 在命令提示符中，输入 chkdsk H: /f（注意替换 H: 为您的磁盘名称）。
    • 这将检查并修复文件系统结构。如果收到消息“由于卷有问题而无法完成操作”，请尝试输入 chkdsk H: /f /r /x 以删除写保护。
    • 输入 exit 关闭命令提示符，然后尝试删除文件。

  2. 更改注册表设置：

    • 按下 Win + R 键，输入 regedit 并按回车。
    • 转到路径：HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\StorageDevicePolicies。
    • 双击 WriteProtect，将 数值数据 从 1 更改为 0。
    • 重启电脑，然后尝试从 SD 卡删除文件。

实测第一种方法可以完美解决问题

文件（夹）无法删除未必代表磁盘出现坏块，本人在执行上述操作后检查出来的磁盘坏块依然是 0kB，文件夹可以正常删除
